# 上身交互动作

在走跑模式的站立分支中接管双臂 14 轴和腰部 3 轴，双腿继续由站立策略控制。
动作资源为 NPZ：`joint_pos` 是 float32 的 `[帧数,17]` 数组，单位 rad，采样率 50 Hz。
列顺序为左臂 7、右臂 7、腰 yaw/roll/pitch，对应关节索引 `[15..28,12,13,14]`。
资源单独提供，不随源码分发。

| 选项 | 文件 | 轨迹时长 | 末帧处理 |
| --- | --- | --- | --- |
| 握手 | `shake_hand.npz` | 1.0 s | 保持至取消或 20 s 到期 |
| 高举挥手 | `wave_above_head.npz` | 5.7 s | 自动收回 |
| 胸前挥手 | `wave_under_head.npz` | 2.6 s | 自动收回 |
| 飞吻 | `blow_kiss_with_right_hand.npz` | 3.0 s | 自动收回 |
| 鼓掌 | `clamp.npz` | 2.2 s | 自动收回 |

进入动作前停止移动。从实测姿态到首帧使用线性过渡，时长由最大关节变化量/2 rad/s 确定。
动作使用 `arm_interactions.kp/kd`，收回时在 1 秒内将目标与增益交还策略。
取消不退出 RL，也不让腿部失能；动作期间的速度输入不会在结束后重放。

模型的上一动作历史保持网络输出，轨迹合成目标另行保存。
接管期间上身位置观测使用配置中的中立姿态，速度保持实测值；
释放后的观测与目标交接由 `interaction_release_frames` 控制。
中立姿态必须与所用策略配套，不是所有模型通用的数值。

TUI 的 A 打开动作列表、Enter 执行、C 取消；Web/App 和手柄使用同一动作目录。
关节序列、持有时间和语音事件检查见 `tests/test_gamepad_bindings.py`。
