# GameSir 手柄遥控

使用 PS4 兼容模式。接收器未连接手柄时可显示为 `3537:2106`，
连接后输入设备为 `054c:09cc`；这是兼容协议标识。
通过稳定的 by-id 路径选择设备，部署前用 `hmi_gamepad --dry-run` 检查物理按键映射。
M 是内部设置键，SDK 的故障确认使用 R3。

`run_g1.sh --real` 启动可选手柄客户端，不依赖网络、不自动获取控制权。
输入与震动在非实时线程处理，客户端退出不关闭三个核心进程。

## 操作表

按键按外壳的 Xbox 字母标记：A 下、B 右、X 左、Y 上。
点按在松开时触发；长按在持续满 1 秒时触发一次，不需要松开，保持不重复。
组合从第二个键按下计时；建议先按 LT/RT，再迅速按动作键。
LB/RB 单键未满 1 秒时加入另一肩键，只计 LB+RB，不再发送 HOME/ZERO。
RT+动作键使用过后，松开动作键但仍按住 RT，不会补发取消；取消须重新单独按住 RT 1 秒。
单独 RT 或 LB/RB 已满 1 秒时，单键命令已经触发；不要提前按住一秒再凑组合。

| 按键 | 触发 | 功能／适用模式 |
| --- | --- | --- |
| 截图键（G 圆键下方小横键） | 点按 | 接管／释放控制权；接管前两个摇杆回中 |
| BACK | 长按 1 秒 | POWER_OFF 掉电；机器人须已由吊装/支撑接住 |
| START | 长按 1 秒 | DAMP 上电阻尼 |
| LB | 长按 1 秒 | HOME |
| RB | 长按 1 秒 | ZERO |
| LB + RB | 长按 1 秒 | RL |
| R3（右摇杆按下） | 点按 | 确认故障，不自动上电或切 RL |
| LT + A | 长按 1 秒 | 走跑运控 |
| LT + B | 长按 1 秒 | 越障运控 |
| LT + X | 长按 1 秒 | 舞蹈运控 |
| Y | 点按 | 走跑／越障运控：慢速／快速切换 |
| RT + A | 点按 | 走跑运控：握手 |
| RT + B | 点按 | 走跑运控：胸前挥手 |
| RT + X | 点按 | 走跑运控：飞吻 |
| RT + Y | 点按 | 走跑运控：鼓掌 |
| RT + ↑ | 点按 | 走跑运控：高举挥手 |
| RT + A/B/X/Y | 长按 1 秒 | 舞蹈运控：分别启动律动 1/2/3/4 |
| RT | 长按 1 秒 | 取消当前动作，回待命 |

越障模式支持 Y 切档，不响应 RT+动作键；舞蹈模式的 RT+ABXY 不会触发手臂动作。
M、G 圆键、L3、右摇杆上下未绑定机器人功能；保留手柄自身设置、开关机等功能。
BACK+START 不再接管，避免与手柄自身长按切换协议冲突。

左摇杆上/下为前进/后退，左/右为左移/右移；
右摇杆左/右为左转/右转，右摇杆上下不使用。推幅决定速度，松开回零。
慢档上限前后 0.6 m/s、横移 0.6 m/s、转向 1 rad/s；
快档仅前进增至 1.5 m/s，倒退仍为 0.6 m/s，横移和转向不变。
走跑与越障的 `command.limits.min_vx: -0.6` 统一限制倒退，手柄、网页与 TUI 均生效。
走跑与越障沿用策略内部平滑，不重复加慢速滤波；舞蹈速度上限为零。

模式可在 RL 中切换，复用已实现的归零、站稳、准备模型和交接流程。
若动作正在执行，先单独 RT 长按 1 秒收回，再切模式。状态切换仍遵守 DAMP→HOME→ZERO→RL。
HOME 完成再 ZERO，ZERO 准备完成再 RL；过早触发会拒绝，松开后重新长按，不自动补发。

手柄不自动抢网页控制权；先在网页释放，再点按截图键接管。
手柄关机/拔接收器只清零并释放控制权，保持当前 FSM；不是掉电急停。
重新开机后先回中、再手动接管。独立硬件急停不能用普通无线手柄替代。

手柄输入设备连接／断开由独立语音进程播“手柄已连接／手柄已断开”。
仅插接收器但未开手柄不播连接，启动时未连接不播断开，接管/释放控制权不触发这两句。
该播报不改变接收器/蓝牙连接方式；生效条件及验证范围见 [语音说明](audio_prompts.md)。

手柄发起的 FSM／运控模式切换，在实际完成回执和目标状态一致时短震一次：
500 ms、强度 180/255。刚按下、模型准备中、请求失败、重复选择当前状态不震；
动作、接管和快慢档目前不额外震动。`--dry-run` 不写震动接口。

## 检查按键

先固定机器人并保持 POWER_OFF，停止会响应按键的运行服务，再在 SDK 根目录执行：

```bash
output/staging/bin/hmi_gamepad application/native/humanoid_unitree_g1/config/g1.yaml --dry-run --policy walk_mnn
```

dry-run 不连接 HMI、不发控制命令或震动。用 `--policy dance_mnn` 检查舞蹈绑定，
该参数不切换实际机器人模式。仅有设备键码不代表外壳按键映射正确，应逐键确认。

震动使用 USB DS4 output report，在设备身份和报告长度核对后发送。
安装器提供精确匹配 `054c:09cc` 的 hidraw 规则，授予 input 组写权限；
接口不可用时只关闭震动，不中断控制输入。协议定义参考
[Linux hid-playstation](https://github.com/torvalds/linux/blob/master/drivers/hid/hid-playstation.c)。
